## 📋 PASOS A SEGUIR (Copia y pega exactamente)

### PASO 1: Hacer Backup de tu carpeta actual

1. Ve a tu Escritorio
2. Busca la carpeta llamada **BARRIO**
3. Haz clic derecho sobre ella
4. Selecciona "Copiar"
5. Haz clic derecho en el Escritorio
6. Selecciona "Pegar"
7. Renombra la copia a **BARRIO_BACKUP_ANTIGUO**

✅ Ahora tienes un respaldo por seguridad

---

### PASO 2: Eliminar la carpeta BARRIO antigua

1. Haz clic derecho sobre la carpeta **BARRIO** original
2. Selecciona "Eliminar" o "Mover a la papelera"
3. Confirma la eliminación

---

### PASO 3: Extraer la carpeta corregida

1. Descarga el archivo **BARRIO_COMPLETO.zip** que te envié
2. Haz doble clic sobre él para extraerlo
3. Arrastra la carpeta **BARRIO_CORREGIDO** a tu Escritorio
4. Renombra **BARRIO_CORREGIDO** a simplemente **BARRIO**

✅ Ahora tienes la carpeta corregida en su lugar

---

### PASO 4: Instalar dependencias (solo primera vez)

1. Abre la Terminal o Símbolo del sistema
2. Escribe (o copia y pega) estos comandos UNO POR UNO:

```bash
cd Escritorio/BARRIO
```
*(Presiona Enter)*

```bash
npm install
```
*(Presiona Enter y espera a que termine)*

✅ Esto instala todo lo necesario para que funcione

---

### PASO 5: Reparar la base de datos

Todavía en la Terminal, escribe:

```bash
node fix_database.js
```
*(Presiona Enter)*

Verás mensajes como:
- ✅ Backup creado
- ✅ Usuarios restaurados
- ✅ Migración completada

✅ La base de datos ya está reparada

---

### PASO 6: Iniciar el servidor

Todavía en la Terminal, escribe:

```bash
node server.js
```
*(Presiona Enter)*

Verás un mensaje:
```
Servidor escuchando en puerto 3000
✅ CONECTADO A CLEVER CLOUD! (Persistencia Activa)
```

✅ El servidor está corriendo

---

### PASO 7: Probar la aplicación

1. Abre tu navegador (Chrome, Firefox, Safari)
2. Escribe en la barra de direcciones:
```
http://localhost:3000
```
3. Presiona Enter

✅ La aplicación debería abrir normalmente

## ❓ SI ALGO SALE MAL

### Problema: "npm: comando no encontrado"
**Solución:** Necesitas instalar Node.js primero
- Ve a: https://nodejs.org
- Descarga la versión LTS (recomendada)
- Instálala
- Luego vuelve al PASO 4

### Problema: El puerto 3000 está ocupado
**Solución:** Detén cualquier otro servidor que esté corriendo
- Presiona Ctrl+C en cualquier terminal que tengas abierta
- Luego vuelve al PASO 6

### Problema: No se conecta a la base de datos
**Solución:** Verifica que ejecutaste el PASO 5 correctamente
- El archivo `barrio.db` debe estar en la carpeta BARRIO
- Si no existe, el script lo creará automáticamente

## 📱 PROBAR EN EL CELULAR

Si quieres abrir la app desde tu celular en la misma red WiFi:
