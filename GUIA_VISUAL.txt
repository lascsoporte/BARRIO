## 💻 PASO 3: Abrir la Terminal

### En Windows:
1. Presiona la tecla `Windows` + `R`
2. Escribe: `cmd`
3. Presiona Enter

```

└─────────────────────────────────────┘
```

### En Mac:
1. Presiona `Command` + `Espacio`

3. Presiona Enter

## 🆘 PROBLEMAS COMUNES

### "npm: comando no encontrado"
```
Solución:
1. Descarga Node.js de: https://nodejs.org
2. Instala la versión LTS (recomendada)
3. Reinicia la Terminal
4. Vuelve al PASO 5
```

### "Puerto 3000 ya está en uso"
```
Solución:
1. Presiona Ctrl+C en todas las terminales abiertas
2. Cierra todas las ventanas de Terminal
3. Abre una nueva Terminal
4. Vuelve al PASO 7
```

### "Cannot find module"
```
Solución:
1. Asegúrate de estar en la carpeta BARRIO
2. Ejecuta: npm install
3. Espera a que termine
4. Vuelve al PASO 7
```

### "Base de datos bloqueada"
```
Solución:
1. Cierra todas las aplicaciones que usen la base de datos
2. Detén el servidor (Ctrl+C)
3. Espera 5 segundos
4. Vuelve al PASO 7
```
